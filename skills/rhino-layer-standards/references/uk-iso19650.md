# UK: BS 1192 to ISO 19650, with Uniclass 2015

BS 1192 layering was superseded in UK practice by the ISO 19650 series (information management with BIM). Layer naming for CAD is now generally defined in the project's BIM Execution Plan (BEP) and Master Information Delivery Plan, not by the standard itself. Recalled from general knowledge: verify against the project BEP.

## Pattern commonly used
`Role-Classification-Presentation`, hyphen separated. Examples:

| Layer | Meaning |
|---|---|
| `A-Wall-External` | Architect, external walls (house style) |
| `A-Pr_25_71-Wall` | Architect, Uniclass 2015 Pr (product) code for walls (code shown as an illustration only: verify the code table) |
| `S-Ss_25_10-Column` | Structure, Uniclass system code (illustrative: verify) |
| `A-Anno-Dims` | Annotation: dimensions |
| `A-Anno-Text` | Annotation: text |
| `A-Grid` | Grid |

Role letters follow the ISO 19650 / BS 1192 role list: `A` architect, `S` structural engineer, `M` mechanical, `E` electrical, `C` civil, `L` landscape (verify the full list in the BEP).

## Uniclass 2015 tables
Prefixes: `Co` complexes, `En` entities, `Ac` activities, `SL` spaces/locations, `EF` elements/functions, `Ss` systems, `Pr` products, `TE` tools and equipment. Codes look like `Ss_25_10_30`. Do not generate codes from memory for deliverables: ask the user for the table extract or verify against NBS.

## Practical use
- Ask for the BEP layer or naming convention first.
- Use a custom scheme JSON if the BEP gives a list.
- Drawing sheet and file names follow the BEP naming (project-originator-volume-level-type-role-number); that is outside layers.
