# Scales and paper

## Metric scales

| Use | Scale |
|---|---|
| Site, urban | 1:500, 1:1000 |
| Overview, floor plates | 1:200 |
| Plans, sections, elevations | 1:100, 1:50 |
| Details | 1:20, 1:10, 1:5 |
| Full-size details | 1:1 |

## Imperial scales

| Scale | Ratio |
|---|---|
| 1/16 in = 1 ft | 1:192 |
| 1/8 in = 1 ft | 1:96 |
| 1/4 in = 1 ft | 1:48 |
| 1/2 in = 1 ft | 1:24 |
| 1 in = 1 ft | 1:12 |
| 3 in = 1 ft | 1:4 |

## Paper (width x height, mm)

| ISO | mm |
|---|---|
| A0 | 841 x 1189 |
| A1 | 594 x 841 |
| A2 | 420 x 594 |
| A3 | 297 x 420 |
| A4 | 210 x 297 |

ANSI A to E: 8.5x11, 11x17, 17x22, 22x34, 34x44 in. ARCH A to E: 9x12, 12x18, 18x24, 24x36, 36x48 in.

## Fit check
Drawing printed size = model extent / scale denominator. Example: a 60 m building at 1:100 is 600 mm wide, fits A1 (841 mm) with margins and title block, not A2 portrait. Leave about 10 mm margin (20 mm binding edge) and the title block strip.

## Detail scale
In Rhino layouts a detail viewport scale is set as page length to model length; for mm model and mm paper, 1:100 is 0.01. Lock detail viewports after setting scale to avoid accidental zoom.
